Ad Experience

Monetization designed to avoid interrupting active puzzle solving.

Ad placement rules

  • Adaptive banner ads on menu screens only.
  • No banner ads while a puzzle is active.
  • Interstitial after game 3, then every 3 completed games.
  • 180-second cooldown between interstitials.
  • Optional rewarded video for extra hints.
  • Emulator shield prevents live ads on emulators.

Build & Release

Run tests, create a debug APK or generate the signed Google Play bundle.

Build commands

1 · Automated unit tests
.\gradlew testDebugUnitTest --continue
2 · Debug APK
.\gradlew assembleDebug
3 · Signed Google Play bundle
.\gradlew buildPlayBundle

What the release task does

1

Compile & optimize
Builds the optimized release variant.

2

Sign the bundle
Uses the configured master_release.keystore.

3

Archive the AAB
Exports the versioned bundle to the release folders.

Signing key alias shown in the project notes: mohsen_apps_master_key.

Release output locations

release_builds/SudokuZen-v1.0.0-b1-YYYYMMDD-release.aab

Version Management

Convenient Gradle tasks for semantic version updates.

Show current version

.\gradlew showVersion

Displays versionName and versionCode.

Patch release

.\gradlew bumpPatch

Example: 1.0.0 → 1.0.1.

Minor / major release

.\gradlew bumpMinor
.\gradlew bumpMajor

Updates the appropriate semantic version segment and versionCode.
